# RAG를 이용한 초개인화 식단 관리 서비스
단순 기록을 넘어, “오늘 뭐 먹을까?”까지 알려주는 AI 식단 코치

<br>

## 🎯 프로젝트 개요

기존 식단 관리 앱의 대부분은 사용자가 **직접 모든 음식을 수동으로 입력**해야 하는 방식을 채택하고 있습니다.  
이로 인해 지속적인 입력 부담이 발생하고, 장기적인 사용률이 크게 떨어지는 문제가 있습니다.

또한 대부분의 앱은 기록된 데이터를 단순히 저장하거나 기본 통계만 제공할 뿐,  
이를 바탕으로 한 **실질적인 맞춤형 식단 추천** 기능은 부족합니다.

더 큰 문제는 개인마다 음식에 대한 신체 반응(소화, 컨디션, 체중 변화 등)이 모두 다르다는 점입니다.  
기존 서비스들은 일반화된 식단 정보만 제공할 뿐, 사용자의 체질, 생활 패턴, 건강 목표를 충분히 반영하지 못하고 있습니다.

**MyMeal**은 이러한 한계를 극복하기 위해 기획되었습니다.

사용자가 기록한 식단 데이터를 기반으로 **개인별 신체 반응을 분석**하고,  
그 결과를 바탕으로 **초개인화된 식단 추천**을 제공합니다.

“무엇을 먹었는지” 기록하는 데 그치지 않고,  
**“앞으로 무엇을 먹어야 하는지”** 구체적인 행동 가이드를 제시하는  
실질적인 의사결정 보조 서비스입니다.

<br>

## 📊 시장 분석

- 국내외 헬스케어 및 다이어트 시장 지속 성장
- 1인 가구 증가, 운동 인구 확대, 만성질환 관리 수요 증가
- 단순 정보 제공을 넘어 **개인에게 최적화된 솔루션**을 원하는 소비자 트렌드 강화
- “같은 음식이라도 사람마다 신체 반응이 다르다”는 인식 확산
- 체질, 생활습관, 건강 목표를 반영한 **초개인화 건강 관리 서비스**에 대한 잠재 수요 급증

<br>

## 🔍 기존 서비스와의 차별점

| 구분                  | 기존 식단 관리 앱                  | **MyMeal** |
|-----------------------|------------------------------------|------------|
| 입력 방식             | 대부분 수동 입력                   | 수동 + 편의 기능 지원 |
| 데이터 활용           | 단순 저장 및 기본 통계             | **개인별 신체 반응 분석** |
| 추천 수준             | 일반화된 식단 정보                 | **초개인화 식단 추천** |
| 초점                  | “무엇을 얼마나 먹었는지”           | **“앞으로 무엇을 먹어야 하는지”** |
| 서비스 목적           | 기록 도구                          | **지속 가능한 건강 관리 코치** |

### MyMeal만의 핵심 차별점
- 사용자의 **누적 식단 데이터 + 개인별 신체 반응**을 종합 분석
- 동일한 음식이라도 사용자마다 다른 컨디션 변화를 학습하여 맞춤형 가이드 제공
- 단순 기록 앱이 아닌, **실질적인 의사결정 보조 서비스** 지향
- 개인의 체질, 생활 패턴, 건강 목표를 반영한 초개인화 식단 추천

MyMeal은 “기록”을 넘어 **지속 가능한 건강 습관 형성**을 돕는 진정한 개인 식단 코치입니다.

<br>

## 🚀 MyMeal이 추구하는 가치

- 사용자가 매일 “오늘 뭐 먹을까?”라는 고민을 덜 수 있도록
- 단순한 데이터 축적이 아닌, **실제 행동 변화**로 이어지는 인사이트 제공
- 개인의 삶에 최적화된 건강한 식단 습관 형성
